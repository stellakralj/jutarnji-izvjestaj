# Jutarnji izvještaj za hotelske managere

Testni zadatak za Rentlio (product design), Stella Kralj.

## Struktura

```
index.html            glavna stranica (razrada)
prototip/index.html   klikabilni prototip, ugrađen u stranicu
assets/img/           slika prototipa za naslovnicu
assets/pdf/           zadatak.pdf (upute zadatka)
```

Stranica i prototip moraju ostati u ovoj strukturi mapa, inače se prototip na stranici ne prikaže.

## Lokalno

Raspakiraj zip i otvori `index.html` u pregledniku.

## GitHub Pages

1. Uploadaj sve datoteke iz mape u novi repozitorij.
2. Settings > Pages > Deploy from a branch, `main`, `/ (root)`.
3. Stranica je dostupna na `https://<korisnik>.github.io/<repozitorij>/`.

Prototip se može otvoriti i zasebno: `prototip/index.html`, a scenarij se bira na traci na vrhu.
